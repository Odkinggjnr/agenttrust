# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in AgentTrust, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email **johnsonakanimoh4@gmail.com** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 48 hours and aim to provide a fix within 7 days for critical issues.

## Scope

The following are in scope for security reports:

- Smart contract vulnerabilities (agent-registry, reputation-engine, stake-manager, dispute-handler, x402-verifier)
- Frontend authentication or authorization bypasses
- SDK vulnerabilities that could lead to incorrect trust verification
- Cross-contract call exploits

## Bug Bounty

We do not currently have a formal bug bounty program, but we deeply appreciate responsible disclosure and will credit reporters in our changelog.
